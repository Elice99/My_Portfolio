THE PROBLEM

Built for SPOTA, a mid-sized B2B tech and manufacturing company, to help the sales team evaluate CRM opportunities and prioritize effort toward deals most likely to close.

APPROACH

Cleaned the pipeline tables in SQL Server, then trained a tuned XGBoost classifier on 6,711 closed deals with a slim 28-feature set, an experiment harness that cut the features that hurt cross-validated scores, and a single evaluation on the held-out test set. Wrapped the model in a FastAPI service with single and batch endpoints, containerized it with Docker, and scored all 1,589 open deals through it.

OUTCOME

Held-out test ROC-AUC 0.6085, 62.8% accuracy with 94.8% recall at the shipped threshold, selected by 3x5 repeated cross-validation. Every quoted number traces to metrics.json, the file the training run writes; the open-deal scoring run is documented as a path test, not a pipeline read.
